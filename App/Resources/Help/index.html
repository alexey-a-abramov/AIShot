AIShot Help

A native macOS screen-capture tool built for both humans and local AI agents.

What is AIShot

AIShot captures a region, window, or display; lets you annotate it; organises captures with notes and project tags; and exposes the same capabilities to local AI agents through an embedded MCP server — all on your Mac, with nothing uploaded anywhere.

Most screenshot tools are built for a person clicking a shutter. AIShot is built for the workflow where an AI assistant also needs to see your screen, act on it, and hand images back — while still being a first-class capture tool for you.

Local-first by design. Captures, recognised text, notes, and tags never leave your machine. The MCP server talks to your agent over stdio and opens no network socket. There is no account, no telemetry, and no cloud upload.

Quick start

  1. AIShot lives in the menu bar — it has no Dock icon. Click the camera icon to open the menu.
  2. Grant Screen Recording permission when asked (see below).
  3. Press ⌘⌥⇧4 and drag to capture a region.
  4. The capture is saved and copied to your clipboard. Paste it anywhere.
  5. Open Dashboard from the menu to browse everything you've captured.

Freeze-frame selection

By default, region capture snapshots the screen the instant you press the shortcut, then lets you select from that frozen image. Menus and tooltips stay open instead of vanishing the moment you start dragging. Cancel and nothing is saved. Turn it off in Settings → Capture if you prefer selecting against the live screen.

Self-timer

Set a 3, 5, or 10 second delay from the menu bar or Settings → Capture — useful for capturing hover states and menus that need a moment to appear. A countdown shows before the shot.

After a capture

Choose what happens automatically in Settings → Capture → Default action:

  • Copy to clipboard — save and copy, ready to paste (default).
  • Open editor — save and open the annotation editor.
  • Save only — save quietly.

You can also configure the capture sound and notification banner in Settings → Notifications.

Screen recording

Press ⌘⌥⇧R or use the menu to start and stop. Pick Video (.mp4) or Animated GIF from the menu bar's Recording Format submenu (or Settings → Capture) before you start. Recordings appear in the Dashboard alongside screenshots.

Notes & project tags

After a capture, AIShot can ask for a short note and a project tag. The tag field is a combo box — type a new tag or pick an existing one.

Tick “Apply this tag to the next captures” when you're about to take a run of related screenshots. Every following capture gets that tag silently, with no prompt, until you turn it off in Settings → Notes & Tags.

Notes and tags are stored in a small JSON database. By default it's a hidden file beside your screenshots; you can make it visible or move it to a folder of your choice in Settings → Notes & Tags → Database.

Search inside your images OCR

AIShot reads the text in your recent screenshots in the background and builds a private, on-device index. That means the Dashboard's search box finds captures by the words that appear inside them — not just by file name or tag.

Search connection refused and you'll get the screenshot of that error from three weeks ago, even though you never named or tagged it. Matching cards show the excerpt that matched.

Indexing runs quietly when the Dashboard is open and only processes images it hasn't seen before. The index is derived data — delete it any time and it rebuilds itself.

Annotation editor

Opens automatically if you've set that as your default action, or via ⌘⌥⇧E, a double-click in the Dashboard.

Tools

  • Select — click any object to move it, or change its colour and size. Annotations stay editable until you save.
  • Arrow, Line, Rectangle, Ellipse — drag to draw.
  • Text — click and type directly on the image.
  • Highlighter — translucent marker.
  • Blur / Pixelate — hide sensitive parts of the image.
  • Counter — numbered step badges that count up automatically (1, 2, 3…).

Image actions

  • Beautify — frames the image on a gradient background with padding and a shadow.
  • Redact — automatically finds and blurs emails, card numbers, and IP addresses.

Everything is undoable — including Beautify and Redact — with ⌘Z and ⇧⌘Z. Esc backs out of whatever you're doing: cancels a text edit, discards an in-progress shape, deselects, then returns to the pointer.

MCP server — let AI agents use your screen

AIShot ships a local MCP (Model Context Protocol) server. MCP is the open standard assistants use to call tools, so any MCP-capable agent — Claude Code, Claude Desktop — can capture and read your screen through AIShot.

An agent launches the bundled stdio bridge, which forwards JSON-RPC requests to AIShot. Every agent shares one capture authority, so your permission grants are reused rather than requested again per tool. It talks over stdio and opens no network socket, so images and recognised text never leave the device.

Setup

1. Register the bundled server with your agent.

Claude Code — one command:

claude mcp add aishot -- /Applications/AIShot.app/Contents/Helpers/aishot-mcp-server

Claude Desktop, or any client with a JSON config:

{
  "mcpServers": {
    "aishot": {
      "command": "/Applications/AIShot.app/Contents/Helpers/aishot-mcp-server"
    }
  }
}

Claude Desktop's config lives at ~/Library/Application Support/Claude/claude_desktop_config.json.

2. Restart your agent so it picks up the new tools. Ask it something like “take a screenshot of my screen and tell me what's in it” to confirm.

Running a dev build? The helper is at .build/debug/aishot-mcp-server in the repo after swift build. Use that path instead.

Safety

  • Capture and read tools run immediately.
  • Tools that synthesise input — click, type, switch app — are always refused by the standalone bridge, because a headless process has no UI in which to confirm them.
  • The server communicates over stdio and opens no network socket at all — nothing is exposed to your network.
  • Agent clicking and typing additionally requires the Accessibility permission.

Troubleshooting

“Screen Recording permission not granted” even though I granted it

macOS ties permissions to an app's exact code signature. If you rebuilt AIShot from source with a different signing identity, the old grant no longer applies. Remove the stale AIShot entry in System Settings → Privacy & Security → Screen Recording, then grant it again. Development builds should be signed with a stable identity (scripts/dev-sign.sh) so the grant persists.

Cards say “File missing”

The capture was moved or deleted outside AIShot, so history points at a file that's gone. Click Clear N missing in the Dashboard header to prune those entries.

My agent doesn't see AIShot's tools

  • Check the helper path exists — the app must be in /Applications for the path above.
  • Restart the agent; most only read their MCP config at launch.

Search doesn't find text I can see in a screenshot

Indexing happens in the background while the Dashboard is open — give it a moment on first run. Very low-contrast or stylised text may not be recognised.
